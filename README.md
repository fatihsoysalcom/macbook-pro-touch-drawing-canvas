# MacBook Pro Touch Drawing Canvas

This example demonstrates a basic drawing application using HTML5 Canvas, simulating the intuitive touch interaction discussed in the article. Users can draw on the canvas using touch (on touch-enabled devices) or mouse, showcasing how a touch screen can enhance creative workflows.

## Language

`html`

## How to Run

Save the code as `index.html`. Open `index.html` in a web browser. Use your finger (on a touch screen) or mouse to draw on the canvas.
